Code and data, 2026-09-24

Everything behind the page. Python 3.12 with qiskit, qiskit-ibm-runtime, qiskit-aer. Put your own IBM Quantum API key in a file and point the scripts at it. Every script has a free sim mode: rehearse there first, then write your prediction down, then spend real minutes.

The page's four panels

  • space_time_same.py: panel 1 (space vs time) and panel 3 (the witness)
  • arrow_panel.py: panel 2 (the arrow)
  • three_box.py: panel 4 (the three-box paradox)
  • three_box_11.py: panel 4, turned up to eleven (the minus one in the 11 corner)
  • dark_link.py: the one-qubit time curve used in panel 1 (and the space/time link tests)

The tests that came back textbook (and the two fakes we caught)

  • dark_floor.py, dark_floor_v2.py: the "remainder" / ordering artifact
  • dark_edge.py: raw readout dots, counting shots off the map

The record

  • PREREGISTRATIONS_AND_RESULTS.md: every prediction as written, then every result
  • SHUTTLE_TEARDOWN.md: the brake check
  • data/: every real-hardware result file (JSON)
